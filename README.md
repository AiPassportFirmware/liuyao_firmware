# Liu Yao (Six Lines Divination) Firmware

A fully offline Wenwang Najia divination application for the FoloToy AI
Passport (ESP32-C3, 240×320 display, three buttons). Hold a question in mind,
cast three coins six times on the device or enter the lines by hand, and read
a complete najia chart with a four-page classical interpretation — no network,
no cloud, no AI service.

This branch (`liuyao`) is a derivative application built on the AI Passport
baseline. The upstream platform overview lives in
[docs/README.md](docs/README.md); the baseline hardware-test demo is not part
of this application.

## What it does

- **Boots straight into the app**: a taiji cover screen, then a guided flow —
  question category → (relationship perspective) → cast date/time → cast
  method → six cast lines → chart → four-page reading.
- **Nine question categories** select the classical useful god (yongshen) per
  traditional rules; relationships optionally follow the male/female
  perspective convention.
- **Two casting modes**: shake on the device (hardware RNG with the
  traditional 6..9 coin distribution) or manual entry of coins already shaken
  offline.
- **True Ganzhi calendar**: day pillar with the late-zi-hour roll, month
  pillar from solar-term boundaries accurate to the minute (2020–2040), year
  pillar from Lichun. The last entered date survives power loss.
- **Full najia chart**: palace and stage, self/other lines, stems-branches
  with six relatives and six spirits, void branches, month break, day clash,
  hidden lines with flying gods, moving-line advance/retreat, and
  six-clash/six-harmony patterns.
- **Four-page classical reading** generated on-device from deterministic
  rules: hexagram overview, useful-god strength and timing, moving lines, and
  a conclusion with a tendency verdict plus a direction-matched classical
  feature line.

## Controls

| Key | Action |
| --- | --- |
| UP / DOWN (click) | Move the selection · adjust date fields · scroll the reading · cycle the manual-entry value |
| OK (click) | Confirm · shake one line · next reading page |
| OK (hold) | Back one level (to the cover from results) |

## Build, test, and flash

```bash
./tools/validate.sh --static    # repository checks + host tests
./tools/validate.sh --firmware  # ESP-IDF build + merged-image verification
```

The complete gate requires an activated ESP-IDF 5.5.3 environment. The
verified merged image flashes at offset `0x0`; see the
[flashing and stored-data policy](docs/development/engineering/firmware-layout.md).
Chinese UI text uses application font subsets generated by
`tools/gen_liuyao_fonts.sh` — regenerate the fonts whenever UI strings change.

## Design notes (device constraints)

- The board has no PSRAM and a small LVGL memory pool. Do not animate
  `transform_scale` here: LVGL 9 renders scaled objects into an ARGB8888
  offscreen layer that cannot be allocated on this target, and the failed
  allocation spins the render thread without backoff, freezing all input.
  Selection feedback uses a shadow pulse instead.
- Page transitions are instant. A full-screen opacity fade exposes stale
  single-buffer content on its first frames and reads as flicker.
- LVGL is not thread-safe: all object access outside the LVGL task happens
  under `bsp_lvgl_lock()`.
